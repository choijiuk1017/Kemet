# KEMET

Unity로 개발한 2D 플랫포머 액션 게임입니다.  
다양한 몬스터와 보스 전투를 중심으로 이동, 전투 및 AI 시스템을 구현한 개인 프로젝트입니다.

## 프로젝트 정보

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | PC |
| 장르 | 2D 플랫포머 액션 |
| 개발 기간 | 2023.02 ~ 2025.02 |
| 개발 인원 | 1인 개발 |
| 개발 환경 | Unity, C# |

## 주요 구현

- 이동, 점프, 슬라이딩 등 2D 플랫폼 이동 시스템
- 콤보 공격 및 패링 기반 플레이어 전투 시스템
- State Pattern과 FSM 기반 몬스터 및 보스 상태 관리
- 순찰형, 돌진형, 마법형, 소환형 몬스터 AI 구현
- 보스 상태에 따른 공격 패턴 및 상태 전환 구현

## AI 구조

몬스터와 보스의 행동을 상태 단위로 분리하고 FSM을 통해 상태 전환을 관리했습니다.

각 몬스터의 특성에 맞는 상태와 전투 패턴을 구성하여 새로운 행동을 확장하기 쉬운 구조로 구현했습니다.
